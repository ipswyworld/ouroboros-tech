Ouroboros Hybrid Blockchain

Our own settlement layer: a DAG-based chain with BFT consensus, subchains and microchains, and a WASM virtual machine.

In development

Agents can use this chain without anyone handing them a private key.

An owner grants an agent a capability envelope, scoped by tool, contract, recipient, value ceiling, rate and expiry. The gateway holds the keys, so an agent cannot act outside its grant.

Twenty tools across read, action and discovery tiers are reachable over MCP by any language model, with a path for a human to approve what an agent proposes.

How it is put together

  • A DAG ledger

    Blocks form a directed acyclic graph, with subchains and microchains, rather than a single line of blocks.

  • BFT consensus

    Byzantine fault tolerant consensus: the nodes agree on the ledger even when some of them fail or misbehave.

  • A WASM virtual machine

    Contracts run in a WebAssembly virtual machine.

  • Enforced limits for agents

    Spending authority for AI agents is set by the owner and enforced by the gateway, not left to the agent's good behaviour.
